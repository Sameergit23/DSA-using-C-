# DSA Practice in C++

A small collection of beginner C++ programs from my early data structures and algorithms practice. Each file is a standalone console program that reads a value from the user and makes a decision with `if` / `else` logic.

## Programs

| File | What it does |
| --- | --- |
| `EvenOdd.cpp` | Reads a number and says whether it is even or odd |
| `PositiveOrNot.cpp` | Reads a number and says whether it is positive or negative |
| `Voting.cpp` | Reads an age and says whether the person is eligible to vote (18 or older) |
| `Grade.cpp` | Reads a score and prints a grade: A (90+), B (75-89), C (50-74), or fail |

## Running a program

You need a C++ compiler such as `g++`:

```bash
git clone https://github.com/Sameergit23/DSA-using-C-.git
cd DSA-using-C-

g++ EvenOdd.cpp -o evenodd
./evenodd
```

Replace `EvenOdd.cpp` with any file in the table.
